# P1 / P2 候选需求池（T-103～T-114）

> 以下 12 项是**建议**，不是已确认的 v1 承诺。只有产品决策通过后才排入正式里程碑。

## P1：v1 后优先评估

- [ ] **T-103｜P1｜智能图标匹配与图标资源管理**
  - 对应需求：NAV-02 的增强。
  - 前置：T-023、T-030。
  - 交付：根据应用名称匹配品牌图标、上传自定义图标、失败回退。
  - 验收：匹配可人工覆盖；外部图标不可用时导航仍可显示。

- [ ] **T-104｜P1｜导航高级布局与个性化**
  - 对应需求：NAV-03、NAV-04 的增强；参考 Q-01、Q-02。
  - 前置：T-027、T-032。
  - 交付：卡片尺寸、背景、更多主题或多级分组（具体内容待确认）。
  - 验收：不破坏现有卡片排序和响应式布局；旧配置可迁移。

- [ ] **T-105｜P1｜容器详情与日志体验增强**
  - 对应需求：INV-03 的增强。
  - 前置：T-053、T-058。
  - 交付：日志过滤/下载、更多容器指标或详情（范围待确认）。
  - 验收：大日志可控、数据明确标注采样时间；不把高级监控作为 v1 必需。

- [ ] **T-106｜P1｜认领外部 Compose 项目为受管应用**
  - 对应需求：INV-04 的增强；决策 Q-06。
  - 前置：T-051、T-056、T-057。
  - 交付：识别外部 Compose project，允许管理员显式认领并保存元数据。
  - 验收：未经确认不自动认领；认领不重建或删除现有容器。

- [ ] **T-107｜P1｜应用版本更新与部署变更**
  - 对应需求：DEP-01 的增强。
  - 前置：T-083、T-087。
  - 交付：模板升级、配置变更与回滚策略（待设计）。
  - 验收：升级失败可诊断；不误删持久化数据。

- [ ] **T-108｜P1｜应用卸载、容器删除与数据保留策略**
  - 对应需求：INV-03 的增强；决策 Q-13。
  - 前置：T-055、T-083。
  - 交付：区分删除容器、卸载 Compose 项目、保留/删除数据的独立确认流程。
  - 验收：导航卡片删除不触发卸载；破坏性操作有明确范围和二次确认。

- [ ] **T-109｜P1｜应用配置与数据备份恢复**
  - 对应需求：NFR-02 的增强。
  - 前置：T-077、T-083。
  - 交付：按应用实例备份 Compose 配置和数据的设计与操作流程。
  - 验收：恢复到测试环境后可验证；不把 Server SQLite 备份等同于应用数据备份。

- [ ] **T-110｜P1｜导航卡片展示关联应用的运行状态**
  - 对应需求：NAV-05 的增强；决策 Q-14。
  - 前置：T-029、T-054、T-057。
  - 交付：可选状态标识，区分 Agent 离线、容器运行状态与应用健康。
  - 验收：不把“容器运行中”错误描述为“应用健康”；卡片无关联时不显示伪状态。

## P2：长期候选

- [ ] **T-111｜P2｜Agent 自动升级**
  - 对应需求：AGENT-04 的增强。
  - 前置：T-101。
  - 交付：签名/校验、分批升级、失败回滚和版本兼容策略。
  - 验收：升级失败不使设备永久失联；不可绕过发布来源验证。

- [ ] **T-112｜P2｜外部应用模板仓库与审核机制**
  - 对应需求：CAT-01 的增强；决策 Q-08。
  - 前置：T-060、T-064。
  - 交付：可配置模板源、版本锁定、信任/审核与缓存策略。
  - 验收：不静默执行未经信任的脚本；外部源不可用不影响已安装应用。

- [ ] **T-113｜P2｜更多 Agent 平台适配（含 OpenWrt 评估）**
  - 对应需求：NFR-04 的增强。
  - 前置：T-100、T-101。
  - 交付：目标平台资源/架构兼容性评估及受支持能力列表。
  - 验收：明确 Docker/Compose 能力限制；不承诺所有 OpenWrt 设备均支持。

- [ ] **T-114｜P2｜多用户与细粒度权限研究**
  - 对应需求：PROD-01 的未来扩展。
  - 前置：v1 需求稳定后。
  - 交付：多用户、导航共享、Agent 操作权限隔离的独立 PRD。
  - 验收：不影响 v1 单管理员行为；完成安全模型后才开始实现。
