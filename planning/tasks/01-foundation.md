# M0 · 工程基础与数据模型（T-001～T-008）

> P0 · 8 项 · 初始状态：全部未完成。目标：让 Web、Server、Agent 具备可启动、可构建、可迁移的基础工程。

- [ ] **T-001｜P0｜确定 Monorepo 目录与包管理策略**
  - 对应需求：PROD-01、NFR-04。
  - 前置：无。
  - 交付：Web、Server、Agent、共享契约、应用模板、部署目录和 planning/ 的职责约定；统一命名和版本策略。
  - 验收：新贡献者可根据 README 找到各模块；目录不包含重复的业务实现；记录 Node/Go/包管理器版本。

- [ ] **T-002｜P0｜初始化 Fastify + TypeScript Server**
  - 对应需求：PROD-01、NFR-04。
  - 前置：T-001。
  - 交付：Server 启动入口、路由注册、统一错误处理、健康探针（Server 自身，不是应用健康检查）、关闭信号处理。
  - 验收：开发模式和生产构建均可启动；未知路由/参数错误返回一致结构；优雅退出释放数据库与连接。

- [ ] **T-003｜P0｜初始化 Vue 3 Web 与路由骨架**
  - 对应需求：PROD-02、NFR-03。
  - 前置：T-001。
  - 交付：Vue 3 + TS + Vite + Tailwind CSS 4 + shadcn-vue 基础项目，首页、登录、后台两模块占位路由。
  - 验收：桌面/移动端均可加载；首页是默认路由；后台两个业务入口名称准确；生产构建成功。

- [ ] **T-004｜P0｜初始化 Go Agent 可执行程序**
  - 对应需求：AGENT-02、NFR-04。
  - 前置：T-001。
  - 交付：Agent CLI、配置加载、版本输出、结构化日志、优雅停止；Linux 目标架构构建脚本。
  - 验收：无 Server 时清楚提示连接失败且可退出；编译产物无需安装 Go；敏感配置不出现在日志中。

- [ ] **T-005｜P0｜建立前后端与跨语言 API/消息契约**
  - 对应需求：AGENT-02、CAT-02、NFR-02。
  - 前置：T-002、T-003、T-004。
  - 交付：共享 TypeScript API Schema、OpenAPI 或等价契约；Agent JSON 消息类型、版本字段与运行时校验约定。
  - 验收：Web/Server 可复用同一接口类型；Agent 能根据公开协议示例构造合法消息；非法字段被拒绝。

- [ ] **T-006｜P0｜SQLite / Drizzle 初始化、迁移和核心实体**
  - 对应需求：AUTH-03、NAV-02、AGENT-01、INV-04、DEP-03、NFR-02。
  - 前置：T-002。
  - 交付：数据库连接、迁移框架、初版管理员/会话、导航、Agent、容器快照、实例、任务及日志模型；必要索引与外键。
  - 验收：全新数据库可一键迁移；重复迁移安全；关键唯一约束可测试；启用合适的 SQLite WAL/事务策略。

- [ ] **T-007｜P0｜配置、密钥管理与本地开发环境**
  - 对应需求：NFR-01、NFR-04。
  - 前置：T-002、T-003、T-004。
  - 交付：环境变量示例、配置校验、开发 Compose、Web/Server 代理与 Agent 本地连接说明；忽略数据库与真实密钥文件。
  - 验收：克隆仓库后按文档启动开发环境；缺失关键密钥时明确报错；真实凭据不会进入 Git。

- [ ] **T-008｜P0｜基础 CI、格式检查与测试命令**
  - 对应需求：NFR-05。
  - 前置：T-002、T-003、T-004。
  - 交付：GitHub Actions 检查 TS 类型、lint、Go 格式与测试、构建；统一开发命令说明。
  - 验收：PR 可自动触发检查；任意一处类型/编译错误使检查失败；CI 不依赖真实生产密钥。

## 里程碑验收

可从空环境启动 Web/Server/Agent 基础程序，数据库迁移成功，CI 能自动检查。M0 **不要求**已经具备用户业务功能。
