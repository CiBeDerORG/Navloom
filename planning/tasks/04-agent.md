# M2 · Agent 注册、通信与设备管理（T-034～T-047）

> P0 · 14 项。Agent 在设备上具有完整 Docker 管理能力，因此**身份认证与命令限制必须先于操作能力**。

- [ ] **T-034｜P0｜Agent 身份与设备持久化模型**
  - 对应需求：AGENT-01、AGENT-04。
  - 前置：T-006、T-009。
  - 交付：唯一 Agent ID、名称、凭据摘要、注册/撤销状态、版本、系统信息、最近心跳。
  - 验收：重复 ID 被拒绝；撤销状态可持久化；设备重连不生成重复设备记录。

- [x] **T-035｜P0｜Server 端 Agent 一次性接入令牌**
  - 对应需求：AGENT-01、AGENT-05。
  - 前置：T-034、T-015；决策 Q-09。
  - 交付：管理员签发有时效的一次性接入令牌、使用后作废、失败限流和审计日志。
  - 验收：令牌不能重复注册第二台设备；未登录管理员不能签发；令牌不以明文长期落库。

- [ ] **T-036｜P0｜Agent 首次配对和凭据安全保存**
  - 对应需求：AGENT-01、AGENT-02。
  - 前置：T-004、T-035。
  - 交付：Agent 配对 CLI/配置流程、独立设备凭据保存、重复配对与失效提示。
  - 验收：首次注册成功后可重连；未配对 Agent 无法接收任务；凭据不写入普通日志。

- [ ] **T-037｜P0｜Server WSS 连接与 Agent 认证**
  - 对应需求：AGENT-02、AGENT-05、NFR-01。
  - 前置：T-005、T-034、T-036。
  - 交付：WSS 接入、设备身份校验、连接生命周期、重复连接策略、消息大小限制。
  - 验收：无效/撤销凭据拒绝；连接断开后状态及时更新；明文或无证书校验连接不被生产配置接受。

- [ ] **T-038｜P0｜Go Agent WSS 客户端与自动重连**
  - 对应需求：AGENT-02、NFR-02。
  - 前置：T-036、T-037。
  - 交付：TLS 证书校验、心跳、断线退避重连、连接状态机、优雅退出。
  - 验收：断网后自动重连；不会产生无限快速重连；服务端重启后无需人工重新配对。

- [ ] **T-039｜P0｜Agent JSON 消息信封、版本与校验**
  - 对应需求：AGENT-02、AGENT-05。
  - 前置：T-005、T-037、T-038。
  - 交付：message_id、type、agent_id、task_id、protocol_version、sent_at、payload 结构与校验。
  - 验收：未知版本/消息类型被安全拒绝；非法 payload 不执行；可关联请求与响应。

- [ ] **T-040｜P0｜心跳、在线状态与最近通信时间**
  - 对应需求：AGENT-03。
  - 前置：T-037～T-039。
  - 交付：心跳处理、超时离线判定、最近通信时间与版本/系统信息更新。
  - 验收：正常连接显示在线；超时显示离线；重连恢复在线且 Agent ID 不变。

- [ ] **T-041｜P0｜Agent 列表和详情管理 API**
  - 对应需求：AGENT-03、AGENT-04。
  - 前置：T-034、T-040、T-015。
  - 交付：管理员查询设备列表、详情、重命名、在线/离线状态及最近心跳。
  - 验收：仅管理员可读；离线设备仍显示历史记录；重命名刷新后保留。

- [ ] **T-042｜P0｜应用实例管理中的 Agent 选择与设备视图**
  - 对应需求：PROD-02、AGENT-04。
  - 前置：T-003、T-041。
  - 交付：后台“应用实例管理”内的设备列表/筛选、在线状态、详情、接入指引。
  - 验收：用户可按 Agent 切换管理视图；不额外创建与产品定位冲突的首页仪表盘。

- [ ] **T-043｜P0｜Agent 凭据撤销与断开连接**
  - 对应需求：AGENT-01、AGENT-05。
  - 前置：T-034、T-037、T-041。
  - 交付：管理员撤销设备接入；Server 主动关闭对应连接并拒绝后续重连。
  - 验收：撤销后旧凭据无法建立新连接；正在连接的设备不能继续接收管理任务。

- [ ] **T-044｜P0｜任务命令路由、请求相关性与超时**
  - 对应需求：AGENT-02、DEP-03。
  - 前置：T-039、T-040。
  - 交付：Server 按 Agent ID 下发命令，消息关联 task_id、响应超时与重连后结果回报入口。
  - 验收：任务不会发送给错误 Agent；超时不自动视为执行失败；重复结果可识别。

- [ ] **T-045｜P0｜Agent 受支持命令白名单与参数校验**
  - 对应需求：AGENT-05、NFR-01。
  - 前置：T-039、T-044。
  - 交付：定义 inventory、container_start/stop/restart、compose_deploy 等受控命令；禁止任意 shell/路径注入。
  - 验收：未知命令被拒绝且记录安全日志；伪造参数无法绕过校验；命令执行绑定已认证设备。

- [ ] **T-046｜P0｜Docker 环境探测与能力上报**
  - 对应需求：AGENT-03、CAT-03。
  - 前置：T-004、T-038。
  - 交付：Agent 探测 Docker API、Compose v2 可用性、操作系统与架构并上报。
  - 验收：Docker 不可用时后台显示明确原因；安装入口不会误认为该设备可部署。

- [ ] **T-047｜P0｜双 Agent 连接与权限隔离集成测试**
  - 对应需求：AGENT-01～AGENT-05、NFR-05。
  - 前置：T-035～T-046。
  - 交付：至少两个 Agent 的配对、断线重连、凭据撤销、命令定向及恶意消息测试。
  - 验收：两个设备独立显示；一个 Agent 凭据无法冒充另一个；撤销后不可操作；无未认证命令执行。

## 里程碑验收

至少两台设备稳定连接云端；可以看到在线状态；Agent 的最高权限不会被未经认证的网络请求直接触发。
