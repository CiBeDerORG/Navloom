  - 验收：无任何已登录页面时零 Agent↔Server 通信；仅首页口令登录导航页也能触发连接；两个页面不重复连接；伪造端点、无效证书和已撤销设备拒绝；关闭最后页面后主动断开。

  - 验收：无人在线 Agent 只监听且网络零通信；无效 Server 客户端证书拒绝；不会在 Agent 端启动任何周期性出站请求；不对公网监听。
