# M2 · 容器池与应用实例管理（T-048～T-059）

> P0 · 12 项。容器池是设备事实快照；Navloom 部署实例是业务记录，两者不可混淆。

- [ ] **T-048｜P0｜Agent 发现所有 Docker 容器**
  - 对应需求：INV-01。
  - 前置：T-046。
  - 交付：使用 Docker Go SDK 列举运行中与已停止容器，采集名称、ID、镜像、状态、端口、labels。
  - 验收：在 Agent 启动前已有的容器也会被发现；非 Navloom 容器不被遗漏；Docker 不可用有明确错误。

- [ ] **T-049｜P0｜Server 接收并持久化容器快照**
  - 对应需求：INV-01、INV-05。
  - 前置：T-039、T-048、T-006。
  - 交付：按 Agent ID 保存/更新容器清单、快照版本和同步时间；区分“容器未发现”和“Agent 离线”。
  - 验收：相同容器 ID 在不同 Agent 不冲突；重复快照不产生重复行；快照仅可由所属 Agent 上报。

- [ ] **T-050｜P0｜Docker 事件增量同步与定期全量对账**
  - 对应需求：INV-01、NFR-02。
  - 前置：T-048、T-049。
  - 交付：监听 Docker create/start/stop/die/remove 事件，定期执行全量扫描校准遗漏事件。
  - 验收：新建/停止/删除容器后后台状态更新；Agent 重启或断线后全量扫描能纠正过期数据。

- [ ] **T-051｜P0｜容器端口、Compose labels 与状态标准化**
  - 对应需求：INV-01、INV-04。
  - 前置：T-048、T-049。
  - 交付：统一端口发布映射、容器状态、Compose project/service labels、镜像信息的传输格式。
  - 验收：同一个容器多端口不会丢失；缺少 Compose labels 时正常显示为独立容器；不会虚构访问 URL。

- [ ] **T-052｜P0｜容器池列表、筛选与详情 API**
  - 对应需求：INV-02。
  - 前置：T-049、T-051、T-041；决策 Q-04。
  - 交付：按 Agent、名称、状态、来源过滤容器；返回详情、分页/限制及 Compose 分组字段。
  - 验收：管理员能查询外部容器；无权限者不能读取设备数据；查询结果包含最后同步时间。

- [ ] **T-053｜P0｜应用实例管理内的容器池界面**
  - 对应需求：INV-02、PROD-02。
  - 前置：T-042、T-052；决策 Q-04。
  - 交付：Agent 筛选、容器搜索、状态标签、端口、镜像、来源、详情与空状态。
  - 验收：外部容器和 Navloom 部署容器均可见；按 Q-04 最终决策展示；不会自动出现在导航首页。

- [ ] **T-054｜P0｜Agent 离线与快照过期提示**
  - 对应需求：INV-05、AGENT-03。
  - 前置：T-040、T-049、T-053。
  - 交付：在线/离线与最后同步时间、快照过期标识、重连后自动刷新。
  - 验收：离线时仍能查看上次容器清单但清楚标注不是实时数据；重连后恢复最新状态。

- [ ] **T-055｜P0｜容器启动、停止、重启操作**
  - 对应需求：INV-03、AGENT-05。
  - 前置：T-045、T-052、T-044。
  - 交付：管理员操作 API、Agent Docker SDK 执行、结果/错误回传、按钮状态反馈。
  - 验收：只能操作选定 Agent 上的目标容器；无管理员会话拒绝；操作失败可见；不提供删除/任意命令入口。

- [ ] **T-056｜P0｜Navloom 已部署应用实例的数据模型与列表 API**
  - 对应需求：INV-04。
  - 前置：T-006、T-041。
  - 交付：AppInstance 的 Agent、模板/版本、Compose project、部署时间、关联任务与列表/详情查询。
  - 验收：外部发现容器不自动创建 AppInstance；同一实例可关联多个容器；实例可跨 Server 重启保留。

- [ ] **T-057｜P0｜实例与 Compose 容器的稳定关联**
  - 对应需求：INV-04、INV-05、NAV-05。
  - 前置：T-051、T-056；参考 Q-05。
  - 交付：使用 Agent ID + Compose project/service 等稳定元数据关联实例与容器，并记录当前容器 ID。
  - 验收：容器重建后实例仍能找到新容器；不同 Agent 同名 Compose 项目不会串联；外部容器保持外部来源。

- [ ] **T-058｜P0｜容器日志查看（建议纳入 v1）**
  - 对应需求：INV-03。
  - 前置：T-044、T-045、T-053。
  - 交付：受限日志查询/流式查看、时间与行数限制、断线处理、后台查看入口。
  - 验收：管理员可查看指定容器日志；非管理员拒绝；超大日志不无限缓存；尽可能过滤已知敏感信息。

- [ ] **T-059｜P0｜容器池发现、操作与关联测试**
  - 对应需求：INV-01～INV-05、NFR-05。
  - 前置：T-048～T-058。
  - 交付：已存在容器、运行/停止、Compose 与独立容器、断线、重建、权限、基本操作测试。
  - 验收：Agent 重连后数据正确；重建不会错绑；从池子创建导航不修改 Docker；外部容器不冒充已安装实例。

## 里程碑验收

可以按 Agent 看到真实容器池，区分来源，执行基本操作，并把发现的容器用于导航卡片关联。
