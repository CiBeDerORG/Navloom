# M4 · 安全、可靠性、联调与发布（T-089～T-102）

> P0 · 14 项。M4 是最终发布验收门槛，但安全、测试与文档应从前面各里程碑同步实施。

- [ ] **T-089｜P0｜关键用户流程端到端自动化测试**
  - 对应需求：PROD-01、PROD-02、NFR-05。
  - 前置：T-018、T-033、T-059、T-088。
  - 交付：首次弱口令、管理员登录、导航管理、容器池关联、模板安装、自动导航的 E2E 测试。
  - 验收：从空数据到创建应用导航的完整流程可重复运行；关键错误分支有覆盖。

- [ ] **T-090｜P0｜首页与管理认证安全回归**
  - 对应需求：AUTH-01～AUTH-05、NFR-01。
  - 前置：T-018。
  - 交付：权限绕过、Cookie 属性、CSRF、限流、会话固定、凭据撤销、弱口令与管理员认证隔离测试。
  - 验收：仅持首页凭据不能读/写任何管理资源；注销或撤销后旧凭据失效。

- [ ] **T-091｜P0｜Agent 认证、消息重放与命令注入测试**
  - 对应需求：AGENT-05、DEP-05、NFR-01。
  - 前置：T-045、T-080、T-081。
  - 交付：伪造 Agent ID、无效证书、撤销凭据、消息重放、恶意任务参数与未知命令测试。
  - 验收：无法借一个 Agent 凭据操作另一个设备；重复任务不会再次执行；不提供通用远程 Shell。

- [ ] **T-092｜P0｜敏感信息脱敏与数据保护审查**
  - 对应需求：CAT-03、NFR-01。
  - 前置：T-068、T-078。
  - 交付：审查弱口令、管理员密码、Agent 凭据、安装环境变量、Compose 文件、任务日志和错误响应。
  - 验收：真实密钥不进入仓库、普通日志、任务日志或前端响应；敏感文件权限合理。

- [ ] **T-093｜P0｜SQLite 备份、恢复与迁移演练**
  - 对应需求：NFR-02、NFR-04。
  - 前置：T-006、T-071。
  - 交付：在线安全备份方式、恢复步骤、版本迁移与回滚说明。
  - 验收：包含导航、Agent、实例、任务的测试数据可恢复；备份过程不产生损坏文件；文档可复现。

- [ ] **T-094｜P0｜并发、唯一约束与幂等测试**
  - 对应需求：DEP-05、DEP-07、NFR-02。
  - 前置：T-073、T-084、T-087。
  - 交付：重复提交、并发安装、重复结果回报、并发导航创建与数据库锁争用测试。
  - 验收：同任务只有一个最终结果和一张自动导航卡片；冲突有明确错误而非静默覆盖。

- [ ] **T-095｜P0｜Server 异常退出与任务恢复测试**
  - 对应需求：DEP-03、DEP-05、NFR-02。
  - 前置：T-071、T-081、T-084。
  - 交付：模拟任务执行中 Server 重启、结果落库前崩溃、导航生成前崩溃的恢复测试。
  - 验收：任务不丢失、不盲目重跑；成功部署的导航可补建且不重复。

- [ ] **T-096｜P0｜Agent 断网、重连与容器快照恢复测试**
  - 对应需求：AGENT-02、INV-05、NFR-02。
  - 前置：T-038、T-050、T-054、T-081。
  - 交付：断网、Server 重启、Agent 重启、长时间离线及恢复后的状态一致性测试。
  - 验收：离线显示最后快照和时间；重连后更新容器池；任务状态能对账。

- [ ] **T-097｜P0｜Docker/Compose 与 Linux 目标平台兼容测试**

## 发布门槛

1. 双层认证隔离通过。
2. 至少两台 Agent 联调通过。
3. 既有容器发现与导航关联通过。
4. Compose 成功/失败、重复任务、断线恢复通过。
5. 自动导航仅创建一张卡片。
6. 云端部署与 Agent 安装文档经真实环境验证。
