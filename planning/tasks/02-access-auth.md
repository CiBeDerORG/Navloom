# M1 · 首页访问与管理员认证（T-009～T-018）

> P0 · 10 项。首页弱口令是只读门禁；管理员认证是独立的高权限会话。

- [x] **T-009｜P0｜设计并迁移认证数据表**
  - 对应需求：AUTH-01～AUTH-05、NFR-01。
  - 前置：T-006。
  - 交付：管理员账户、密码哈希、首页凭据摘要/撤销标记、管理员会话与认证版本等字段。
  - 验收：首页凭据不能作为管理员会话；数据库不存弱口令/密码明文；凭据可独立撤销。

- [x] **T-010｜P0｜实现首次管理员安全初始化**
  - 对应需求：AUTH-04。
  - 前置：T-009；决策 Q-10。
  - 交付：部署配置或 CLI 一次性初始化管理员；重复执行与已初始化场景处理。
  - 验收：没有可被公网抢注的管理员注册入口；初始化后不能覆盖已有管理员；错误配置清楚提示。

- [x] **T-011｜P0｜弱口令与管理员密码哈希、验证限流**
  - 对应需求：AUTH-01、AUTH-05、NFR-01。
  - 前置：T-009。
  - 交付：密码安全哈希（如 Argon2id）、常量时间验证、按 IP/标识限流与统一失败响应。
  - 验收：明文不落库/日志；多次错误输入触发限流；错误信息不泄露账号是否存在。

- [x] **T-012｜P0｜首页弱口令验证与长期凭据签发**
  - 对应需求：AUTH-01、AUTH-02。
  - 前置：T-009、T-011；决策 Q-11。
  - 交付：验证 API、随机凭据签发/哈希保存、持久化 HttpOnly + Secure + SameSite Cookie、凭据续期策略。
  - 验收：首次输入正确可进入；刷新/关闭重开仍免输入；前端 JS 无法读取凭据；清除 Cookie 后重验。

- [x] **T-013｜P0｜首页只读路由与管理 API 访问隔离**
  - 对应需求：AUTH-01、AUTH-03、NFR-01。
  - 前置：T-012。
  - 交付：服务端首页读权限中间件与管理员权限中间件；权限拒绝返回规范。
  - 验收：只有首页凭据时能读导航但无法编辑导航、列出 Agent、访问容器或下发任务。

- [ ] **T-014｜P0｜弱口令入口页面与自动跳转**
  - 对应需求：AUTH-01、AUTH-02、NFR-03。
  - 前置：T-003、T-012、T-013。
  - 交付：首次口令页、错误/限流提示、凭据自动校验、成功跳转首页。
  - 验收：新浏览器出现验证页；已记住浏览器直接进首页；过期/撤销凭据返回验证页而非空白。

- [x] **T-015｜P0｜管理员登录、退出与会话 API**
  - 对应需求：AUTH-03、NFR-01。
  - 前置：T-009、T-011。
  - 交付：管理员用户名/密码验证、独立会话 Cookie、退出与会话查询、CSRF 防护。
  - 验收：弱口令无法登录管理；退出后旧会话不可用；跨站请求无法绕过管理 API 保护。

- [ ] **T-016｜P0｜后台修改弱口令、撤销首页凭据**
  - 对应需求：AUTH-01、AUTH-05。
  - 前置：T-012、T-015；决策 Q-11。
  - 交付：修改首页弱口令 API、全量撤销已记住浏览器的操作与后台设置 UI。
  - 验收：修改/撤销后旧浏览器重新要求输入；非管理员无法调用；新口令不回显到日志。

- [ ] **T-017｜P0｜管理员登录页、后台路由守卫与修改密码**
  - 对应需求：AUTH-03、NFR-03。
  - 前置：T-003、T-015。
  - 交付：管理员登录页、管理入口、后台路由保护、退出按钮、修改密码界面。
  - 验收：直接打开管理 URL 需登录；正确登录后能进入两个业务模块；退出后不可通过浏览器后退操作管理 API。

- [x] **T-018｜P0｜认证矩阵与持久凭据自动化测试**
  - 对应需求：AUTH-01～AUTH-05、NFR-05。
  - 前置：T-013～T-017。
  - 交付：访客/首页凭据/管理员的权限矩阵测试，Cookie 生命周期、撤销、限流与 CSRF 测试。
  - 验收：PRD 权限矩阵全部通过；首页凭据不能访问任何管理接口；管理员登录不依赖首页弱口令。

## 里程碑验收

首次访问需弱口令；已记住浏览器免输入；管理后台独立登录；修改弱口令可撤销旧凭据；未授权请求被 Server 拒绝。
