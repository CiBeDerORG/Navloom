# M1 · 导航首页与导航页管理（T-019～T-033）

> P0 · 15 项。导航卡片必须独立于 Docker 存在，且首页只显示用户编排的内容。

- [ ] **T-019｜P0｜导航分组、卡片与可选关联模型**
  - 对应需求：NAV-02、NAV-03、NAV-05。
  - 前置：T-006。
  - 交付：卡片稳定 ID、名称、URL、图标、描述、组 ID、排序、可空关联类型/ID；迁移与约束。
  - 验收：不关联任何对象也能保存；删除卡片不级联删除容器/实例；分组排序可持久化。

- [ ] **T-020｜P0｜导航首页布局与卡片组件**
  - 对应需求：NAV-01、NAV-04、PROD-02。
  - 前置：T-003、T-019；参考 Q-02、Q-03。
  - 交付：导航首页头部、分组、卡片、图标、名称、描述与打开 URL 交互。
  - 验收：默认路由是导航首页；未配置卡片时有空状态；点击卡片只打开链接、不调用管理接口。

- [ ] **T-021｜P0｜导航首页只读查询 API**
  - 对应需求：NAV-01、AUTH-01。
  - 前置：T-013、T-019。
  - 交付：按组和顺序返回可展示卡片的只读 API，不暴露容器敏感详情或管理员字段。
  - 验收：首页弱口令凭据可读取；无有效凭据不可读取；响应排序稳定。

- [ ] **T-022｜P0｜导航卡片 CRUD 管理 API**
  - 对应需求：NAV-02、NAV-06。
  - 前置：T-015、T-019。
  - 交付：新增、读取、修改、删除卡片的管理员 API，URL/名称校验与事务。
  - 验收：只有管理员能写；无关联卡片创建成功；删除卡片不触发 Agent 或 Docker 操作。

- [ ] **T-023｜P0｜手动新建/编辑导航卡片弹窗**
  - 对应需求：NAV-02、NAV-06。
  - 前置：T-020、T-022；参考 Q-03。
  - 交付：名称、URL、图标、描述、分组、可选打开方式表单；编辑与删除确认。
  - 验收：可独立添加 GitHub 等外部链接；字段可修改；非法 URL 给出可读提示。

- [ ] **T-024｜P0｜导航分组管理 API**
  - 对应需求：NAV-03、NAV-06。
  - 前置：T-019、T-015；决策 Q-01。
  - 交付：分组 CRUD、顺序、删除分组时的卡片迁移/处理策略。
  - 验收：分组排序保存；删除含卡片分组不会静默丢失卡片；仅管理员可写。

- [ ] **T-025｜P0｜导航分组编辑界面**
  - 对应需求：NAV-03、NAV-06。
  - 前置：T-023、T-024。
  - 交付：新建、重命名、删除、重排分组，明确删除确认和迁移结果。
  - 验收：操作后首页分组实时或刷新后保持一致；空分组有可理解的展示方式。

- [ ] **T-026｜P0｜导航卡片拖拽排序与跨组移动**
  - 对应需求：NAV-03、NAV-06。
  - 前置：T-022、T-024、T-025。
  - 交付：管理界面拖拽、排序 API、乐观更新失败回滚。
  - 验收：刷新页面排序不丢失；跨组移动正确；失败时提示并恢复原位置。

- [ ] **T-027｜P0｜首页搜索、响应式与基础主题**
  - 对应需求：NAV-04、NFR-03。
  - 前置：T-020、T-021；参考 Q-02。
  - 交付：按名称搜索、移动端布局、基础明暗主题和可访问性处理。
  - 验收：手机屏幕不横向溢出；键盘可搜索和打开卡片；切换主题后文本对比度可读。

- [ ] **T-028｜P0｜创建卡片时选择关联来源**
  - 对应需求：NAV-05。
  - 前置：T-023、T-052、T-056。
  - 交付：在卡片弹窗中选择无关联/应用实例/容器池；支持 Agent 筛选和搜索。
  - 验收：选择来源不强制绑定；取消选择后仍可保存；外部容器可被选中。

- [ ] **T-029｜P0｜卡片关联 API 与稳定标识**
  - 对应需求：NAV-05、INV-05。
  - 前置：T-019、T-049、T-056；决策 Q-05。
  - 交付：关联对象类型/ID 校验、Agent/Compose/service 等稳定识别信息，关联失效处理。
  - 验收：重建容器不会误关联其他设备；容器删除不自动删除卡片；不存在对象有明确反馈。

- [ ] **T-030｜P0｜容器/实例元数据预填导航表单**
  - 对应需求：NAV-05、CAT-04。
  - 前置：T-028、T-029。
  - 交付：名称、图标、候选端口/URL 等可识别信息预填；支持全部手动覆盖。
  - 验收：不将 EasyTier IP:端口强制写成唯一地址；无候选 URL 时仍可手动填写。

- [ ] **T-031｜P0｜关联失效与离线状态提示**
  - 对应需求：NAV-05、INV-05。
  - 前置：T-029、T-054。
  - 交付：后台显示关联容器已消失/Agent 离线；导航卡片本身继续保留。
  - 验收：设备离线或容器消失时不会删除或禁用原有链接；提示不误称为健康检查。

- [ ] **T-032｜P0｜导航页管理完整布局与首页数据刷新**
  - 对应需求：NAV-06、PROD-02。
  - 前置：T-023、T-025、T-026。
  - 交付：管理后台一级入口“导航页管理”、卡片列表/编辑/排序流程、保存后首页数据刷新。
  - 验收：管理员能在一个模块内完成所有导航编辑；首页只展示保存的编排内容。

- [ ] **T-033｜P0｜导航独立性与端到端回归测试**
  - 对应需求：NAV-01～NAV-06、NFR-05。
  - 前置：T-021～T-032。
  - 交付：卡片 CRUD、分组/排序、独立链接、关联容器、失联保留和权限测试。
  - 验收：删除卡片无 Docker 副作用；刷新后布局一致；从容器池创建的卡片 URL 可人工修改。

## 里程碑验收

Navloom 已可作为独立导航产品使用；已有容器关联入口在 M2 完成后启用，M1 不要求 Agent 已接入。
