# M3 · 应用目录、模板与安装表单（T-060～T-070）

> P0 · 11 项。模板是可信、版本化的部署声明；安装表单不是任意命令执行入口。

- [ ] **T-060｜P0｜确定 v1 模板来源与目录规范**
  - 对应需求：CAT-01、CAT-02。
  - 前置：T-001；决策 Q-08。
  - 交付：明确内置模板/外部仓库策略、版本锁定、审核规则、目录命名与模板更新方式。
  - 验收：文档能说明模板从何处加载、如何版本化、谁能修改；不会静默执行未审核的远程脚本。

- [ ] **T-061｜P0｜设计 YAML 应用模板元数据**
  - 对应需求：CAT-02。
  - 前置：T-060、T-005。
  - 交付：模板 ID、版本、名称、描述、图标、分类、架构限制、Compose 资源、导航默认值 Schema。
  - 验收：能用模板描述单容器与多服务 Compose 应用；错误字段给出明确校验失败。

- [ ] **T-062｜P0｜设计 JSON Schema 安装参数规范**
  - 对应需求：CAT-02、CAT-03。
  - 前置：T-061。
  - 交付：字符串、数字、布尔、枚举、默认值、必填项、敏感项、端口与路径输入的 Schema 约定。
  - 验收：必填缺失、类型错误、枚举越界均拒绝；Web 与 Server 的校验结论一致。

- [ ] **T-063｜P0｜安全的 Compose 参数渲染与变量映射**
  - 对应需求：CAT-03、DEP-07。
  - 前置：T-061、T-062。
  - 交付：模板参数到 Compose/env 的受限映射、路径与 project name 约束、禁止 Shell 插值执行。
  - 验收：恶意参数不能改变预定执行命令或越权写入任意路径；渲染结果可预览和验证。

- [ ] **T-064｜P0｜模板解析器、Schema 校验与版本检查**
  - 对应需求：CAT-02。
  - 前置：T-061～T-063。
  - 交付：Server 加载可信模板、校验元数据与参数 Schema、识别版本和平台约束。
  - 验收：损坏模板不能进入可安装目录；相同 ID 的版本冲突有明确处理；解析错误可定位。

- [ ] **T-065｜P0｜应用目录查询与模板详情 API**
  - 对应需求：CAT-01。
  - 前置：T-064、T-015。
  - 交付：目录列表、搜索/分类、模板详情、参数 Schema、适用平台和导航默认值 API。
  - 验收：仅管理员可读取安装敏感字段；未受信任模板不展示为可安装；版本与详情一致。

- [ ] **T-066｜P0｜应用实例管理中的应用目录界面**
  - 对应需求：CAT-01、PROD-02。
  - 前置：T-042、T-065。
  - 交付：应用卡片、名称/图标/说明、分类、详情、安装入口和无可用模板空状态。
  - 验收：用户能从管理后台找到模板并开始安装；不会在导航首页直接展示应用商店。

- [ ] **T-067｜P0｜JSON Schema 动态安装表单**
  - 对应需求：CAT-03、DEP-01。
  - 前置：T-062、T-065、T-066。
  - 交付：按 Schema 生成参数表单、默认值、必填校验、Agent 选择、提交前错误提示。
  - 验收：新增符合规范的模板无需手写专用前端表单；不合法参数不能提交。

- [ ] **T-068｜P0｜安装敏感参数的输入与日志保护**
  - 对应需求：CAT-03、NFR-01。
  - 前置：T-062、T-067。
  - 交付：密码/令牌字段遮蔽、敏感字段传输与任务持久化策略、日志脱敏规则。
  - 验收：浏览器调试日志、Server 普通日志和任务日志不输出敏感明文；管理员可正常提交必要参数。

- [ ] **T-069｜P0｜安装弹窗导航卡片预填与编辑**
  - 对应需求：CAT-04、DEP-06。
  - 前置：T-023、T-067；决策 Q-07。
  - 交付：根据模板填入卡片名称、图标、分组、URL；全部可编辑；保存为任务导航草稿。
  - 验收：提交前可修改任意导航字段；不会仅根据 EasyTier IP 推断最终可访问 URL；默认成功创建一张卡片。

- [ ] **T-070｜P0｜模板示例与动态表单测试**
  - 对应需求：CAT-01～CAT-04、NFR-05。
  - 前置：T-061～T-069。
  - 交付：至少一个简单应用和一个多容器 Compose 模板、合法/非法输入及敏感字段测试。
  - 验收：示例模板可通过解析和表单验证；恶意/缺失参数被拒绝；导航默认值可人工覆盖。

## 里程碑验收

用户能在后台选择可信应用模板，选择 Agent，填写经过校验的安装参数，并编辑将来生成的导航卡片草稿。
